# ARC Studio Operating System

## Purpose

The ARC Studio Operating System defines how ARC thinks, designs, builds, learns, and evolves.

Every project, product, client engagement, and internal decision follows this operating system.

Technology may change.

The operating system remains.

Design systems that improve how people, organisations, and intelligence work together.

# Every Project Must Answer

Why does this exist?

Who benefits?

What problem does it solve?

What system does it improve?

What knowledge does it create?

Can it be reused?

Does it increase ARC's long-term capability?

If the answer is "no"...

We redesign.
