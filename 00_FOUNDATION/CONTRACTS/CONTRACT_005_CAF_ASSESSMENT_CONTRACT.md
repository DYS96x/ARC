# CONTRACT_005 — CAF Assessment Contract

Version: 1.0.0  
Status: Draft  
Authority: HOLY ARC Standards  
Classification: Internal

---

# Contract

> CAF provides the organisational assessment capability of the ecosystem by discovering reality, understanding current capability and identifying improvement opportunities.

---

# Purpose

Define the relationship between CAF and systems requiring organisational understanding.

CAF exists to establish:

- Mission understanding
- Vision alignment
- Current reality
- Target state
- Capability gaps
- Improvement opportunities

---

# CAF Responsibility

CAF owns:

- Organisational discovery
- Mission analysis
- Vision analysis
- Target-state definition
- Current-reality assessment
- System discovery
- Health assessment
- Gap analysis
- Priority analysis
- Roadmap recommendations

---

# CAF Does Not Own

CAF does not own:

- Operational execution
- Final implementation
- Workflow management
- Constitutional governance
- Permanent knowledge storage

---

---

# Required Inputs

CAF requires:

- Organisation context
- Available evidence
- Stakeholder input
- Current objectives
- Constraints
- Desired outcomes

---

# CAF Outputs

CAF provides:

- Assessment findings
- System understanding
- Identified gaps
- Priorities
- Recommendations
- Roadmap options

---

# Evidence Requirements

CAF assessments must distinguish:

```text
Confirmed Fact

↓

Observation

↓

Assumption

↓

Unknown

↓

Recommendation
```

Recommendations must not be presented as facts.

---

Relationship:

```text

```

# Relationship With WOS

Relationship:


---

# Relationship With VOID

VOID may assist CAF through:

- Analysis
- Pattern recognition
- Explanation
- Recommendation support

VOID does not replace CAF ownership.

---

# Assessment Lifecycle

CAF follows:

```text
Discover

↓

Collect Evidence

↓

Analyse

↓

Validate

↓

Assess

↓

↓

```

---

# Quality Criteria

This contract is satisfied when:

- Reality is assessed before solutions.
- Evidence is visible.
- Assumptions are separated.
- Recommendations are explainable.
- Findings create reusable knowledge.

---

# Violations

The following violate this contract:

- Recommending solutions without understanding reality.
- Presenting assumptions as facts.
- Executing without ownership transfer.
- Removing evidence.
- Skipping assessment stages.

---

# Final Principle

> CAF understands where an organisation is. It does not decide where it must go.
