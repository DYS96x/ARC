# Architecture Definition

> Runtime architecture defines how ARC systems operate together during active use while preserving boundaries, state, intelligence and feedback.

---

# Purpose

Define the operational behaviour of the ARC ecosystem.

Runtime architecture explains:

- How requests move.
- How systems interact.
- How state changes.
- How outcomes return to knowledge.
