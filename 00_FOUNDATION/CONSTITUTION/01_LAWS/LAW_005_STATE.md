# LAW 005 — State

Version: 1.0.0  
Status: Ratified  
Authority: HOLY ARC Constitution  
Classification: Internal

---

# Law

> Every constitutional system shall distinguish live state from persistent memory, historical record and constitutional knowledge.

State represents the present.

History preserves the past.

Knowledge captures what has been learned.

These concepts shall never be confused.

---

# Purpose

Define how constitutional state is created, managed, recovered and governed while preserving institutional integrity.

---

# Derived Rules

## R005.1 — State Definition

State represents the current operational condition of a constitutional system.

Examples include:

- Active workflow
- Runtime context
- Current focus
- Pending actions
- Session information
- Temporary calculations
- Operational status

State is dynamic.

---

## R005.2 — Separation

State shall remain distinct from:

- Memory
- History
- Knowledge
- Evidence

Changing state shall never rewrite historical records.

---

## R005.3 — Ownership

Every state shall have one constitutional owner.

Examples:

- WOS owns workflow state.
- ARC owns persistent memory.
- ARC OS owns execution state.
- HOLY ARC owns constitutional governance state.
- VOID owns reasoning session state.

Ownership shall be explicit.

---

## R005.4 — Lifecycle

Every state shall progress through a defined lifecycle.

Typical stages include:

- Created
- Active
- Updated
- Suspended
- Resumed
- Completed
- Archived
- Disposed

No state shall exist outside a governed lifecycle.

---

## R005.5 — State Transitions

Every transition shall be:

- Valid
- Observable
- Authorised
- Auditable

Invalid transitions constitute constitutional violations.

---

## R005.6 — Recovery

Critical state shall define recovery behaviour.

Recovery may include:

- Restore
- Restart
- Reconstruction
- Rollback
- Manual recovery

Recovery shall preserve constitutional integrity.

---

## R005.7 — Synchronisation

Where state is shared:

- Ownership remains singular.
- Synchronisation rules shall be explicit.
- Conflicts shall be detectable.
- Resolution shall be auditable.

Synchronisation shall never duplicate ownership.

---

## R005.8 — Expiration

Temporary state shall define:

- Expiration condition
- Timeout
- Disposal rule
- Archive rule where applicable

Temporary state shall not persist indefinitely without governance.

---

# Constitutional Tests

State complies with LAW 005 when:

- Ownership is explicit.
- State is distinct from memory.
- Lifecycle is defined.
- Recovery is documented.
- Synchronisation preserves ownership.
- Historical records remain immutable.

---

# Violations

The following violate LAW 005:

- Treating runtime state as permanent memory
- Hidden state
- Multiple owners
- Invalid state transitions
- Missing recovery
- State rewriting history
- Uncontrolled persistence

---

# Constitutional Mapping

LAW 005 governs:

- WOS workflow state
- ARC OS execution state
- ARC persistent memory separation
- HOLY ARC constitutional state
- ARC reasoning context
- Sprint OS sprint state
- CAF assessment state

---

# Audit Criteria

LAW 005 passes audit when:

- State ownership is explicit.
- State transitions are governed.
- Historical integrity is preserved.
- Recovery is defined.
- Runtime failures cannot compromise constitutional records.

---

# Final Principle

> State represents the present. Memory preserves the past. Knowledge prepares the future.
