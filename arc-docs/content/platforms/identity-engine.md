# Identity Engine

## Purpose

The Identity Engine establishes trust across every ARC platform.

Everything begins with identity.

Before permissions.

Before workflows.

Before AI.

Before knowledge.

The system must know who or what is interacting with it.

---

# Core Principle

Every action has an identity.

Every identity has responsibility.

Every responsibility is auditable.

# Authentication

Supported methods:

- Password
- Passkeys
- MFA
- SSO
- OAuth
- API Keys
- Service Accounts

Authentication proves identity.

---

# Authorisation

Authentication answers:

Who are you?

Authorisation answers:

What are you allowed to do?

Permissions should always follow least privilege.

---

# Permissions

Permissions should be:

Explicit

Documented

Auditable

Revocable

# Definition of Success

A successful Identity Engine ensures:

Every action has an owner.

Every permission has a purpose.

Every decision can be traced.

Every platform shares a common trust model.
