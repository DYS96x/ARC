# Architecture Decision Records

## Purpose

Architecture Decision Records (ADRs) capture the significant technical and architectural decisions made within ARC.

Every important decision should be recorded.

Future engineers should never need to guess why a decision was made.

Each ADR documents:

- Context
- Decision
- Alternatives Considered
- Consequences
- Status
- Owner
- Date

An ADR represents a decision at a point in time.

It may later be superseded, but it is never rewritten.

Architecture evolves through new ADRs rather than rewriting history.
