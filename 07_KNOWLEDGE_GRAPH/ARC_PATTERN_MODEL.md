# Definition

A pattern represents a repeated or meaningful relationship identified through evidence over time.

Patterns allow ARC to recognise behaviour, predict possibilities, and improve future decisions.

---

# Core Pattern Principle

A relationship explains a connection.

A pattern explains repeated behaviour.
