# Definition

A relationship represents the connection between entities within the ARC knowledge graph.

Relationships describe how entities influence, depend on, exchange, transform, or learn from each other.

ARC intelligence emerges from relationships.

---

# Core Relationship Principle

Nodes represent existence.

Relationships represent meaning.

The graph becomes intelligent through connected relationships.
