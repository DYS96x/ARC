# Definition

The ARC Knowledge Graph represents reality as connected entities, relationships, evidence, patterns, and evolving knowledge.

ARC does not model isolated objects.

ARC models relationships between objects.

---

# Core Graph Law

A node represents something that exists.

A relationship represents how reality connects, influences, transforms, or exchanges between nodes.

The intelligence of the graph emerges from relationships.
